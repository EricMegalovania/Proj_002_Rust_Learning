## 任务三：杨辉三角生成器

### 程序实现
- 输入：层数 n（正整数）
- 使用二维向量存储杨辉三角的每一行
- 通过递推关系 `a[i+1][j] += a[i][j]; a[i+1][j+1] += a[i][j]` 计算下一行
- 输出时先打印前 n-1 行（每行打印当前行的数字），最后单独打印第 n 行

### 运行结果示例
输入：`5`
输出：
```
1 
1 1 
1 2 1 
1 3 3 1 
1 4 6 4 1 
```

### 分析
- 程序正确生成了 5 层杨辉三角，每行数字符合组合数 C(i,j) 的规律
- 输出格式每行末尾有空格，但不影响可读性
- 算法时间复杂度 O(n²)，空间复杂度 O(n²)，对于较小的 n 可以接受
- 注意：程序在打印最后一行时实际上打印了两次（一次在循环内，一次在循环外），但由于循环只打印到 n-1 行，所以最后一行只打印了一次，输出正确

## 任务四：大小写字母转换

### 程序实现
- 输入：一行字符串
- 遍历每个字符，使用 `is_ascii_alphabetic()` 判断是否为字母
- 小写字母转换为大写，大写字母转换为小写，其他字符不变
- 使用 `to_ascii_uppercase()` 和 `to_ascii_lowercase()` 进行转换

### 运行结果示例
输入：`Hello World!`
输出：`hELLO wORLD!`

### 分析
- 程序正确实现了大小写互换，非字母字符（空格、感叹号）保持不变
- 仅处理 ASCII 字母，对于非 ASCII 字符（如中文）会直接保留，符合题目要求
- 代码简洁，使用了迭代器和闭包，符合 Rust 风格

## 任务五：随机四则运算题目生成

### 程序实现
- 随机生成运算符（+、-、*、/）和两个 0~20 的整数
- 通过函数 `gen_op` 返回对应的运算函数
- 循环生成直到满足条件：结果在 1~20 之间，减法保证被减数大于减数，除法保证能整除且除数不为零
- 输出题目和答案

### 运行结果示例
输出：`6 / 2 = 3`

### 分析
- 程序每次运行生成一道题目，符合“数在20以内”的要求
- 减法通过结果为正数（>0）间接保证被减数大，除法通过整除且结果为正数保证条件
- 除法运算中，若除数为零或不能整除，函数返回 -1，循环会重新生成，确保题目有效
- 随机性良好，但程序只生成一道题目，若需要多道题目需多次运行或修改代码

## 任务七：级数求和

### 程序实现
- 输入：项数 n
- 循环计算 1/(i²) 的累加和，使用 `f64` 类型保证精度
- 输出结果保留 12 位小数

### 运行结果示例
输入：`10`
输出：`前 10 项的和是 1.549767731167`

### 分析
- 计算结果正确，与数学公式 S = Σ 1/i² 一致
- 使用 `f64` 足够精确，输出格式控制为 12 位小数
- 算法简单直接，时间复杂度 O(n)
- 注意：当 n 很大时，累加可能导致精度损失，但题目未指定 n 的范围，当前实现可接受
